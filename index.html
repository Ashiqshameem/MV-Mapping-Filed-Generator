GDM–MV mapping field generator

Paste an existing mapping row for a symbol, pick the fields you need, and get new rows that copy every property from it. Only FIELD and the last part of MODEL URI change.

model://EEX_FUT_CEZ/EU.EL.DE.EEX.B.PBL.20260101/SETTLE → OPEN / HIGH / LOW
1

Paste the mapping rows

Copy one or more full rows straight from Excel (tab-separated) or from the CSV. The header row is optional. You can paste several symbols at once; the CLOSE row of each symbol is used as the reference.

2

Choose the fields to create

Pick one, a few, or all. Fields a symbol already has in your paste are skipped for that symbol unless you turn that off.

3

Check the MODEL URI endings

Each field maps to a GDM column at the end of the URI. Defaults come from the patterns in the three reference files, using the symbol’s template when it has its own rule (for example, the HE_ assessment templates map HIGH to ASK and LOW to BID). Edit any ending to override it for all symbols.
